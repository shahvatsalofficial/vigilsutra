# DataShield

Part of VigilSutra AI, created by Vatsal Shah.

`VS-PRIV-001` flags password-like values in log calls. `VS-PRIV-002` flags common tracker snippets. These are engineering prompts, not a GDPR, DPDP, or CCPA determination.

Do not say the project is compliant.
