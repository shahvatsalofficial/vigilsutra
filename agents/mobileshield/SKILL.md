# MobileShield

Part of VigilSutra AI, created by Vatsal Shah.

There is no Android, iOS, or mobile-framework rule. Say "mobile applications: not assessed."

If the repository also contains JavaScript, TypeScript, or Python, those files still get the normal code and secret rules. That is not a mobile assessment.
