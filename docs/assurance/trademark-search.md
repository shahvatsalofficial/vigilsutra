# Preliminary name search

> **Important:** this is a quick web search, **not** a trademark clearance, legal opinion or availability guarantee. Have a trademark attorney run a formal search before significant promotion.

Date: 2026-11-01. Searched the name "VigilSutra" (and with `.com`, `.ai`, `.io`) in general web search.

## Findings

- No result for a product, company or website called "VigilSutra" was found.
- Results for similar names in security software exist, so a conflict in the "Vigil-" family cannot be ruled out:
  - **VIGILES**, registered in the United States for software that monitors the security and integrity of computer systems and IoT devices.
  - **VIGILANT365**, registered for application-security monitoring software.
  - **VIGILANT**, registered for cybersecurity hardware and consulting.
  - **THREATCERT**, pending, same owner as VIGILANT365.
- On 2026-10-31 the npm registry had no package named `vigilsutra` (it is now ours). GitHub had no repository of that name for this account.
- Domains `vigilsutra.com`, `.ai` and `.io` were **not** looked up in a registrar; do that.

## Interpretation

"VigilSutra" is a different word from those marks, but they share the "Vigil" stem in the same field (security software), which is the pattern examiners and opposing parties look at. The risk is moderate and unquantified here.

## Recommended next steps

1. Formal search in the USPTO and WIPO Global Brand databases, and in India (the author's jurisdiction) and the EU.
2. Check domains and social handles; register the ones you want.
3. Decide on a fallback name; the name appears in `package.json`, `README.md`, `CITATION.cff`, the docs and the `vigilsutra` command.
4. Keep using only "VigilSutra" with `AI` as a descriptor, never the registered marks above.
