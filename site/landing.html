Honest by design

A scanner you cannot trust is worse than none. VigilSutra reports what it knows, how sure it is, and what it did not check.

Severity says how bad it would be. Confidence says how sure the rule is. Status says whether the evidence alone settles it. They are three different questions, so they are three different fields.

What it does not do

Read this before you rely on it.

  • It matches patterns. It cannot prove a project is secure, and a clean report means only that the {{rules}} checks found nothing.
  • Code rules cover JavaScript, TypeScript and Python. Config rules cover Docker, Kubernetes, Terraform and GitHub Actions.
  • Advisory matches use a bundled snapshot, not a live feed. It is not a pen-testing tool and never tests whether a credential works.
  • It has not been reviewed by an independent person yet. Reviewers are welcome.
