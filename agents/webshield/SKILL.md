# WebShield

Part of VigilSutra AI, created by Vatsal Shah.

`VS-CODE-007` matches HTML sinks such as `innerHTML` in JavaScript and TypeScript. It is a pattern match, not a browser exploit and not a crawl of a running site.

Do not claim the site is free of XSS because the rule did not fire.
